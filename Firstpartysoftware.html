Goober-site

In advance yes, the name is bad. This website was created on the 28th of June 2025, with one goal, to provide information about satellites for free to anyone who wished. Created in the following months of the creation of an amateur satellite listening station that was created by me starting with a simple RTL-SDR Blog V3 and a telescoping V dipole. In the websites infancy, I had first posted the sites URL to a discord channel for people to give feedback on, one user said “It looks like an excel spreadsheet”; with that being said, it really did look like a Microsoft Excel spreadsheet.

Everything was hard coded, meaning all satellite data in its primitive database was physically typed in the html file; until recently, the website had poor graphics because of its primitive HTML and CSS from, causing accessibly and performance issues. For contrast, the site wasnt readable on mobile devices until recently when I decided to use Bootstrap for formatting and graphics, greatly improving performance, accessibility, and its overall appearance.

The first thing Bootstrap was used to change was the Index.html page (Home page), with the first thing added being a navigation bar at the top of the page rather than a table with hypertext links used for the sites navigation. After the navbar was created, the footer was completely overhauled with new links while still containing the copy right notice for this software. I, really recommend Bootstrap for your websites, its free and easy to use it can be found in the footer of every page.

Satdb

The satellite database was first hard coded into a HTML file until when development for the .json version started on Saturday, 28th of March 2026. With the first hard coded version being hard to maintain and edit, with low readability and flexibility with no search capabilities; relying on the users to manually find each satellite on the webpage, providing a purpose for a new more flexible database. Thus, in turn the .json version was created on the 28th of March 2026 after I had gained the necessary knowledge to create a more advanced database; requiring more than just the bare basics on web development that I self-taught myself during the early versions of this website when I was 15.

A few months after my 16th birthday, I decided to rework the whole database into a .json file, with the file being read and interpreted by a script made in JavaScript displaying the data into the HTML page on a table; and allowing for search capabilities in the new database. Partway through migrating data to the .json database, I had realized that having a whole database in a .json file and on one table was extremely inefficient; I stopped migrating data to the .json file while I learned basic database design in one of my senior high school classes. Until the 17th of July 2026, when I decided to spend the rest of my school break on Satdb using SQLite3; and continuing to use JavaScript for data interpretation and html to display the data in a table.

With multiple lookup tables rather than one, helping reduce duplicated data and allows for more advanced search queries; in addition, the new database allows for easier data correction; with the added benefit of allowing for the ability to change one data entire, updating for all entries containing that data. Increasing entire and data integrity overall. - Bailey
